=== Smart MCQ Manager ===
Contributors: smart-mcq
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 0.1.0
License: GPLv2 or later

Step 1 foundation for a WordPress MCQ exam manager.

Features:
- Admin-only question bank
- Four answer options (A, B, C, D)
- Correct-answer selector and explanation
- Subjects and topics classifications
- WordPress permission and nonce checks

Install:
1. WordPress > Plugins > Add New Plugin > Upload Plugin.
2. Upload smart-mcq-manager-step1.zip and activate.
3. Open Smart MCQ > Add MCQ Question.
4. Add the title, choices, explanation, and assign Subject and Topic.

Note: This release is a starting foundation, not a student exam platform.
